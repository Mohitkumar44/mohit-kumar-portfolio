## 2. Theme Switching Experience

The current Dark/Light switch is noticeable and feels unprofessional.

I want the switching experience to feel as smooth as premium websites like Apple, Vercel, Linear, Stripe or Framer.

Requirements:

- Eliminate visible flashing.
- Eliminate layout shifting.
- Eliminate noticeable repainting.
- Theme changes should feel instant and fluid.

Implement:

• Proper CSS variables for all colors
• Theme classes instead of replacing inline styles
• Smooth color transitions (250–350ms)
• GPU-accelerated animations where appropriate
• Fade transition only for colors—not layout
• Preserve scroll position
• Preserve component state
• No re-rendering of the page
• No flickering on images
• No flashing white screen
• Apply transitions only after initial page load to prevent FOUC (Flash of Unstyled Content)

Also:

- Store the theme in localStorage.
- Respect prefers-color-scheme on first visit.
- Update the HTML class before the page paints.
- Ensure the navbar, cards, buttons, forms, footer, and all sections transition smoothly.

The toggle button itself should also be improved:

- Animated sun/moon icon
- Small rotation animation
- Smooth scale on hover
- Beautiful micro-interactions
- Premium appearance

Do NOT redesign the website.

Keep the existing design, but make the theme switching experience feel production-quality and indistinguishable from high-end professional websites.
